# To-Do List Console Application

A simple To-Do List application built using Python. This project allows users to manage their daily tasks through a menu-based console program.

## Features

- Add a task
- View all tasks
- Delete a task
- Update a task
- Clear all tasks
- Save tasks to a file
- Load saved tasks when the program starts
- Handle invalid input using exception handling

## Concepts Used

- Python Lists
- Loops
- Functions
- Conditional Statements
- File Handling
- Exception Handling
- List Methods
- `enumerate()`

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code.
3. Run the following command:

```text
python todo.py
```
