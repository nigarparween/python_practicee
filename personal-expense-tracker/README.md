# Personal Expense Tracker

A simple Python-based Personal Expense Tracker that helps users manage and organize their daily expenses.

## Features

- Add expenses
- View all expenses
- Calculate total expenses
- Search expenses by category
- Edit expenses
- Delete expenses
- Save expenses to a JSON file
- Load saved expenses
- Input validation
- Automatically save expenses when exiting

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists and Dictionaries
- Exception Handling

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python main.py
```

4. Follow the menu options shown in the terminal.
